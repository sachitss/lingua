# Releases

Each folder holds one Lingua release: its packaged files, release notes and, from v0.2.0, a test report and checksums. Large iOS and web builds are listed in `FROM_BUILD` and attached from the CI build instead of being stored in git. The "Publish releases" workflow turns each folder into a GitHub Release with the same tag.
